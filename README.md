# Library

About the project
This project is a digital library where users can explore a collection of books. The purpose of the assignment was to build an interactive website using HTML, CSS and JavaScript.

Users can:

Browse a collection of books.
Filter books by genre.
Sort books by rating, from highest to lowest or lowest to highest.
Generate a random book suggestion if they don't know what to read.
The process
I started by linking the CSS and JavaScript files to the HTML file and setting up the basic structure of the page.

I then created the HTML structure and styled the page with CSS, using the provided Figma design as inspiration. I focused on creating a clear layout and choosing colours, fonts and button styles that matched the design.

Next, I connected the JavaScript file to the HTML and worked on displaying the different books from an array of book objects.

Once I was happy with the overall design, I started focusing on the JavaScript functionality. I implemented the genre filtering and rating sorting features to make it easier for users to navigate the library.

Finally, I explored how to create a random book generator. This feature allows users to discover a book from the collection with just one click.

Tools and techniques
HTML - Structuring the website and its content.
CSS - Styling the page, using Flexbox and CSS Grid for layouts, and adding hover effects.
JavaScript - Working with arrays and objects, DOM manipulation, event listeners, filtering, sorting and random selection.
Figma - Used as inspiration for the visual design.
What I would improve with more time
If I had more time, I would like to:

Make the website fully responsive for mobile devices and tablets.
Improve the random book feature by displaying the selected book separately while keeping the full library visible.
Add more books to the collection.
Improve the overall user experience with additional interactive features.
